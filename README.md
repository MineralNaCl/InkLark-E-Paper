# InkLark E-Paper

InkLark E-Paper 是一个电子墨水屏硬件设计与驱动代码开源项目。

## 目录

- [`hardware/`](hardware/)：硬件设计文件。
- [`img/`](img/)：项目图标、丝印素材与硬件预览图片。
